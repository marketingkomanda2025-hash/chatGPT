# Передышка

Личный календарь отпусков на русском языке. Выберите первый и последний день в календаре, введите название и выберите цвет. Нажмите на цветной период или карточку отпуска, чтобы изменить даты, название, цвет или удалить отпуск. Повторный выбор того же дня создаёт однодневный отпуск. Можно переходить между месяцами во время выбора периода. Пересекающиеся отпуска разрешены, в годовой статистике дни учитываются один раз.

Данные сохраняются в localStorage этого браузера. Сервера, аккаунтов и синхронизации с внешними календарями нет. Очистка данных браузера удалит планы. Если браузер запрещает сохранение, приложение показывает предупреждение.

## Разработка

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Vite выводит адрес и порт сервера в терминале. Готовые статические файлы находятся в `dist/`.
